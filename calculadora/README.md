# 🧮 Scientific Calculator

A modern and responsive scientific calculator developed using **HTML**, **CSS**, and **JavaScript**. The application provides advanced mathematical operations, number base conversions, keyboard support, and a clean user interface with light and dark themes.

---

## 🚀 Features

- Scientific calculator
- Basic arithmetic operations
- Trigonometric functions
- Logarithmic and exponential functions
- Factorial calculations
- Power and square root operations
- Constants (π and e)
- Decimal, Binary, Octal, and Hexadecimal converter
- Keyboard shortcuts
- Light/Dark mode
- Copy result functionality
- Responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Math.js
- SweetAlert2

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/juanjose0624/scientific-calculator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or run it using a local server such as **XAMPP** or **VS Code Live Server**.
