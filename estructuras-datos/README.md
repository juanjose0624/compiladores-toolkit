# Estructuras de Datos Aplicadas a Compiladores

Este proyecto contiene la implementación en **PHP** de diversas estructuras de datos lineales y no lineales (listas enlazadas, listas dobles, pilas, colas y árboles) enfocadas en la teoría, análisis y operaciones fundamentales del desarrollo de compiladores.

---

## 🛠️ Estructuras Implementadas

* **`listas.php`**: Implementación de listas simplemente enlazadas para manipulación dinámica de elementos.
* **`listas_dobles.php`**: Implementación de listas doblemente enlazadas para recorridos bidireccionales.
* **`pilas.php`**: Estructura LIFO (*Last In, First Out*) útil para evaluación de expresiones y análisis sintáctico.
* **`colas.php`**: Estructura FIFO (*First In, First Out*) aplicada a colas de procesamiento y lectura de tokens.
* **`arbol.php`**: Estructura jerárquica no lineal para la construcción y representación de árboles sintácticos.
